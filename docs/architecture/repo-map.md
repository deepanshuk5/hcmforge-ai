# HCMForge Repository Map

This repository contains the complete HCMForge-AI project.

## backend/
Contains the Java backend application.
Later this will include Spring Boot, REST APIs, PostgreSQL, Security, Payroll, Spring AI, RAG, and Agentic AI integration.

## web/
Contains the frontend application.
Later this will include the React + TypeScript user interface for login, employee management, attendance, leave, payroll, and AI features.

## ai-lab/
Contains Python-based AI experiments and learning implementations.
This will include Machine Learning, Deep Learning, tokenization, embeddings, a tiny Transformer/LLM, LoRA fine-tuning, and other AI experiments.

## infra/
Contains infrastructure and deployment files.
Later this will include Docker, Docker Compose, Terraform, Kubernetes, and deployment configuration.

## scripts/
Contains utility and automation scripts.
Examples: health checks, deployment helpers, diagnostics, load-testing helpers.

## evals/
Contains evaluation datasets and test cases for AI features.
Later this will include RAG evaluation, prompt-injection tests, tool-calling tests, and Agentic AI evaluation cases.

## sample-data/
Contains synthetic data used for development and testing.
Examples: employees, attendance records, payroll data, HR policies.

## docs/
Contains project documentation.
This includes architecture decisions, system design, database design, API notes, and project explanations.
